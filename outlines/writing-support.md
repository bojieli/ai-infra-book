# 阅读路径与配套格式

本页落实跨章推算、分层阅读、参数和预测记录。大纲中的题目已经选择并编号，数据包、完整参考解和本书实测仍待扩写。

## 共同前置

所有路径先读第一章四节（全景→数字→估算→设计短例），再读 2.1–2.2 的执行与生成基线、2.3–2.5 的结构比较及 2.6 的汇总，再进入 3.1–3.6，建立单位、模型状态、请求与训练需求。第一章先使用独立的 70B 教学假设；进入模型章节后，基础读者跟 Qwen3-8B，MoE 先完成一组配置；V4-Pro／K3 的完整迁移题可后读。物理资源不熟悉时补 4.1、4.3、4.7，跨卡问题先补 6.1–6.4 与 7.2–7.3。第六章先随 6.2、6.3 形成并行候选，再读 6.4、6.5 校正通信和拓扑；6.6 检查共享容量，6.7 用实验 6-10 完成规模与推理实例数量选择。 第七章按 7.1–7.2 建立跨节点路径与流量，7.3–7.4 推导访问和交接规则，7.5–7.6 检查共享、故障与任务收益；首次阅读先完成原则和基础时序题，协议字段、事务序模式与远端排序变体后读。

这些是选择重点的路径。压缩阅读时，先读所略章节的章首前置和章末交付；遇到不熟悉的状态、通信或恢复机制，回查对应完整小节。可选综合练习从对应路径选一项未解配置，提交一页任务、候选、资源与状态图、未知量及最小补测；复用各章记录，不另开方法章节。延伸题按实际项目需要选择，不要求安装所有后端。

第九章按从单实例到分布式服务、PD、AF、专家负载均衡、共享 KV、服务生命周期、完整部署七节展开。9.3 先完成同机异构分析再进入跨机 AF；9.5 按身份、取回、持久化、路由建立状态复用；9.6 讲启动、重配置和故障，9.7 才组合方案。核心实验 9-4、9-7、9-10 分别交付计算分工、状态复用和完整部署判断，原有十项实验与九项配图全部保留。

## 跨章记录与参数档案

[跨章推算](decision-record.md)已经给出逐章新增约束、需要重做的选择和现有材料入口。[记录模板](decision-record-template.json)用于保存一次预测及修订：未知字段为 null；证据类型、单位、原始值、日期与来源单独存储，不能用实测字段装教学假设。

参数档案以模型／后端／硬件／任务为联合版本。容量分逻辑、驻留峰值与暂存；流量按接口和重复次数；计算按实际精度与操作；关键路径按真实依赖。公式记录假设、输入单位和适用范围；架构档案连接现有案例笔记及固定原件，避免抄出另一份会漂移的规格表。

## 数据包与参考分析的制作要求

每项核心练习配题目输入、预测区、可运行脚本或来源记录、结果分析和一项改变条件的迁移题。参考分析解释错误假设怎样导致不同结论。配图从同一输入生成，引用论文曲线时保留原条件。特定设备尚未测量时提供已有公开记录，明确它与本书拟测配置的差异。

配套综合练习在题目和答案之间隔离新增条件，读者先封存判断，再读取反例或测量。预测记录写明到期日、指标范围与推翻条件；到期复核追加观察并保留原文。当前模板没有伪造预测、实验完成状态或未来结果。

第八章阅读顺序为 8.1 基线 → 8.2 批处理 → 8.3 KV → 8.4 压缩／卸载 → 8.5 推测解码 → 8.6 服务验证。实验展示编号已随顺序调整，原始目录不改名，查阅[旧新映射](../research/ch08-reorganization-2026-09-10/README.md)。
