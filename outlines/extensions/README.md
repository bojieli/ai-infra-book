# 逐章扩写资料

主大纲用少量案例推进判断；本目录保留本轮修改前已整理的完整推导、参数、源码定位和实验变体，供正式扩写与进阶阅读。全部原稿另保存在[修订前快照](../../research/outline-revision-2026-09-08/before.tar.gz)，证据和未完成测量的状态沿用原记录。

第 2–12 章按当前章、节和实验顺序重排，正文各节可直接跳转到完整材料。**第 1 章经过整章重写，其扩写资料按原有细目保存，细节节号和实验含义属于来源结构，不能视作新正文的一一对应。原第 13 章已拆入前十二章，具体落点见[迁移记录](../../research/ch13-redistribution-2026-09-09/README.md)；旧章号仅用于历史来源查证。** 当前题目、核心选择和推导顺序以主大纲为准；历史占位编号留作查证。

新补充材料先判断能否推进推导、提供反例或校准假设，再决定进入主大纲还是本目录。版本演进、完整型号表、更多算法实现和设备实验可独立查阅，不成为读完主线的额外前置。
