# 受控Chat采集与同输入重放

固定四轮读书会规划问题，Qwen3-8B实际生成回答并追加到下一轮消息；96-token上限、自然EOS、thinking关闭。是本实验构造的对话，不是用户/生产日志。存每轮完整消息、模板输入token、回答、时间。之后两轮随机策略顺序seed912，每次清缓存并新启原生Router，三个策略各重放同四轮完整输入。固定原始回答作后续上下文，不随重放答案分叉；核对输出差异而不预设相同。记录原生worker归属、实际缓存、自然结束或截断、请求和token加权命中、前次同worker完成后的间隔。立即续发的间隔包含客户端开销，不冒充人类思考或工具耗时。无队列压力、无远端存储，不提供远端取回p95。
