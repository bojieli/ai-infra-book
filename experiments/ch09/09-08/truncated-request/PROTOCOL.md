# 截断文件的实际请求恢复

复制正常恢复实验的65个文件到独立storage，按原consumer顺序记录定位首个页面，截短末2字节。固定同一模型、输入和SGLang配置，启动新引擎后发一个1024输入/16输出请求。观测器只记录原始get/set返回或异常，异常原样重新抛出。

初始化最多观察180秒；从request_start起观察60秒。记录正常返回、请求异常、子进程退出或观察窗口到期，不把窗口到期解释为永久死锁。到期后仅终止本次Popen创建的独立进程组，并记录清理前后成员和退出码。时间是实验观察窗口，不是服务配置的超时或SLO。

原缓存、已封存实验、共享服务与calculations保持不变。本次单条件单请求，不推广损坏类型或故障概率。
