# 两批实际验证工作调度

本地Python独立子进程，固定两个逻辑执行槽位，不冒充机器仅有两个CPU。B批三任务t=0可用、A批三任务t=30ms可用；每任务600000次SHA256，B2为3000000次长尾。候选到达是控制输入，不是模型实际生成时刻。每任务实际compile Python验证代码并执行，先独立完整工作取得两长度参考digest。

三个非抢占调度器：固定每批一槽（不可借用）、FIFO（共享两槽，按可用时刻/序号）、A批目标优先（共享两槽，已运行不抢占）。优先目标A事先指定，不窥视实际运行时间。每轮三策略seed1105随机顺序，三轮共54任务。记录可用/dispatch、编译、执行、反馈行抵达及子进程wait回收时间；只在回收后释放逻辑槽。对比A/B批全部反馈、最后资源释放和总CPU工作，不将一批收益当作全部任务收益。已有超时实验原件复用、不重跑；不调用calculations。
