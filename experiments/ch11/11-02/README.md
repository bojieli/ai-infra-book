快照文档要求模板envd至少0.5.0，并明确快照过程中活动连接会断开。因而文件、进程内存恢复与客户端连接恢复是不同检查，首个工具完成还应包含重连。当前暂停文档另有按区域逐步启用的拒绝/回退行为；不能将新文档中的行为当作所有实际部署已具备的保证。

模板与快照的文档性能描述没有提供这项受控对照的原始延迟分布，因此不填创建、恢复或首工具毫秒数。summary.json中的计时和状态实测字段全部为null；不能用本地进程暂停或普通文件复制冒充E2B microVM恢复。

## 独立核对与后续测量

运行 python3 analyze.py，仅需Python标准库：核验两份来源SHA、六项契约定位、五种比较路径，生成summary.json。sources.json保存URL和取回日期，availability.json保存运行条件检查，manifest.json封存文件。本目录独立携带来源，不依赖另一个session工作目录。

PROTOCOL.md具体定义相同模板、文件nonce、常驻进程内存nonce、活连接、实例身份、重连及首工具计时。它是待执行的测量协议，不是结果。Agent续接应验证运行时状态，RL干净重置应验证旧状态没有泄漏；这些是本实验的验证目标，不是未经实测的性能推荐。

容量和成本推算仍归calculations；本次未改动该目录或原有资料，没有GPU任务。实际E2B四路径及首工具时间仍未完成，全书最终跨session实验及论文复核尚未开始。
