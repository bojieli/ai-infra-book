# 实验 11-7：实际任务用量记录

从本书现存代理执行日志提取 **21个正常结束的turn、17个thread ID、17个worker目录**。每条保留原始用量事件与最终交付文字，没有重跑任务，也没有复制中间命令、启动失败或依赖调试记录。不同日志中有相同thread ID，因此21不是21个独立任务或用户请求。

这些记录可以补充实际用量证据，**不能证明订阅、API、中转的月度完成成本**。`turn.completed`只证明日志协议正常结束；任务质量验收、账单金额、产品额度、完整月度覆盖、具体模型与方案均保持未知。最终文字是执行者自述，不当独立验收。缺少记录的额度受阻任务也不能按零个计。

## 取数与复现

`records/index.json`固定取数时所有一级worker目录下`*events.jsonl`文件的范围、完整原文件SHA/字节数，以及选中行的行号、字节偏移、SHA。`records/*.jsonl`保存这些行的原始字节：thread开始、turn开始、正常完成用量、最后一条agent消息。原文件此前可能按用户要求清理过调试历史，因此不是服务端完整审计日志。没有依赖mtime猜测执行月份，也不读取其他session历史或账号凭据。

离线分析只依赖Python标准库：

```sh
python3 analyze.py
python3 analyze.py /tmp/usage-replay
```

重新提取用显式来源目录和新输出目录，避免覆盖封存原件：

```sh
python3 extract.py --source-root /path/to/parallel-workers --out /tmp/usage-records-new
```

231项断言核对摘录SHA、原始行字节数/哈希、单turn边界、终止事件非重复和非负整数字段。独立复核还将每行按byte offset回读原文件，确认摘录未改写；临时目录分析重放逐字一致。以上只验数据口径，不代表任务验收或支付核对。

## 剩余实验

需要一个固定的月度任务清单及各任务验收门槛，关联订阅、API、中转的实际完成/未完成身份、产品用量和账单。当前17个worker执行的是不同实验子任务，且有恢复turn，不能拿它们当三种付费方式的配对试验。可购买与否不影响本实验：没有可换算的用量就保留未知，不编造额度或费用交点。公开计费快照和费用计算归另一个计算任务，本目录不重复；11-7保持部分完成。
