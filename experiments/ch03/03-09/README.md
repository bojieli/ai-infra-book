# 实验 3-9：Llama 与 Qwen 的训练投入

对应正文 3.5。从固定公开报告抄录 7–8B 与大模型两组输入，计算 D/N、6ND 近似和代际增长倍数；MoE 单列总参数与激活参数，保留数据质量与阶段差异。

## 独立运行

```bash
python3 run.py    # 现场调用 calculations/calc.py training-history，产物写入 results/
```

只需 Python 3.8+ 标准库。输入由该命令从固定官方原件抄录并做哈希校验，本实验不重算，也不添加报告之外的数字。

## 大模型

| 模型 | 参数代理 | 训练 token | D/N | 6ND | 相对首行 | GPU 小时 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Llama-1 65B | 65.2 B | 1.4 T | 21.5 | 5.48e23 | 1.0× | 1,022,362 |
| Llama-2 70B | 70.0 B | 2.0 T | 28.6 | 8.40e23 | 1.5× | 1,720,320 |
| Llama-3.1 70B | 70.0 B | 15.0 T | 214 | 6.30e24 | 11.5× | 7,000,000 |
| Llama-3.1 405B | 405.0 B | 15.6 T | 38.5 | 3.79e25 | **69.2×** | 30,840,000 |
| DeepSeek-V3（预训练） | 37.0 B 激活 | 14.8 T | 400 | 3.29e24 | 6.0× | 2,664,000 |
| DeepSeek-V4-Flash | 13.0 B 激活 | 32.0 T | 2,462 | 2.50e24 | 4.6× | 未公开 |
| DeepSeek-V4-Pro | 49.0 B 激活 | 33.0 T | 674 | 9.70e24 | 17.7× | 未公开 |

三条判断：

1. **同样规模的模型，三代之内训练投入涨了 43 倍**（Llama-1 7B → Qwen3 8B）。涨的几乎全部是 D 而不是 N：参数只从 6.7B 到 8B（1.2×），token 从 1T 到 36T（36×）。这是 2023 年之后最重要的一条趋势——**给定参数预算，继续加数据仍在起作用**。
2. **D/N 从两位数涨到四位数**。Chinchilla 的 D/N≈20 只符合 Llama-1 65B（21.5）和 Llama-2 70B（28.6）。此后所有模型都远超它：Llama-3.1 8B 是 1,875，Qwen3 8B 是 4,500。这不是拟合失效，而是**优化目标变了**——从“给定训练预算求最优损失”变成“给定推理成本求最优质量”，后者要求更小的 N 和更大的 D。
3. **MoE 让这张表不能直接比**。DeepSeek-V4-Flash 的 6ND 只有 2.50e24（Llama-3.1 405B 的 1/15），但那是按 13B **激活参数**算的；它的总参数远大于此，权重容量需求要按总参数算。用哪一个数取决于问的是计算还是容量。

## 保留的差异

- 参数量是各报告的名义值代理，不是 checkpoint 精确权重计数。
- 6ND 只是近似：不含注意力随长度增长的部分（实验 3-6 显示 32K 序列上它低估 51%），也不含非矩阵与优化器工作。
- 训练 token 数的口径各报告不同（是否含多阶段、是否含重复），不能当作数据质量指标。
- **“投入更大”不等于“模型更好”**：阶段组成、数据质量与后训练都不在这张表里。
