# 3-3 可完成题集的运行前协议

首批 1,024 与 4,096 总输出上限的两次实跑，44 个候选全部因预算截断、思考未结束，三策略均 0/8，无法在“相同质量要求”下比较代价。关闭 thinking 的诊断批自然结束但全段严格 JSON 解析全部失败。本批改变**题集难度**与**总输出上限**，其余条件保持。

固定条件：Qwen3-8B 同一快照、thinking 开启、temperature 0.6／top_p 0.95、每候选总输出上限 8,192（同时包含 thinking 与最终输出，不是独立 reasoning 配额）、`max_model_len` 16,384、APC 关闭、eager、`max_num_seqs=2`、`gpu_memory_utilization=0.30`、`kv_cache_memory_bytes=6 GiB`、引擎 seed 303、按 trial 与候选索引固定采样 seed。

题集：八道子集计数题，元素数 4/5/6/7 各两道，答案由穷举与 DP 交叉验证，运行前不进入模型输入。难度代理＝元素数，运行前固定。

三个策略：串行依次生成两个**独立**候选（不携带前一回答续推）；并行在同一 GPU 引擎同时提交两个候选（不是两张卡）；按规模分配对元素数 ≤5 的题只生成一个候选，其余两个。两轮、八题、三策略共 48 组、80 次请求；组顺序用 seed 303 预先打乱。

评分：最终答案必须在 `</think>` 之后为严格 JSON 且只含整数 `count`。有效候选多数投票，平票取候选索引较小者，全无效判失败。真值只在选完后用于评分，不参与选择或预算分配。失败与截断全部保留。

不做的事：不读取真值决定重试或追加预算；不把存在一个正确候选直接算作成功；不将并行较短的耗时解释为正确任务收益；共享 GPU，不声称独占计时；两轮八题不构成普适质量结论。
