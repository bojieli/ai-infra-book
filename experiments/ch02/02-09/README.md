# 实验 2-9：请求条件下的模型选择

对应正文 2.6（进阶延伸）。固定同一请求输入，完整比较四个模型的 prefill、decode 每步与整段工作、常驻状态、读取与更新，并列出使模型选择成立的质量条件。

## 独立运行

```bash
python3 run.py    # 现场调用 calculations/calc.py request-model-comparison，产物写入 results/
```

资源侧数字由统一计算项目用各自官方 config 现场生成，本实验不另行实现公式。质量侧是两组实跑记录：[paired-retrieval/](paired-retrieval/README.md) 与 [multikey/](multikey/README.md)。

## 资源对照

同一请求：命中前缀 6,144、新输入 2,048、输出 256、batch=1（K3 取 compact 路径，路由取均匀）。

| 模型 | prefill TFLOPs | 首步 decode TFLOPs | 首步历史读取 | 整段 decode TFLOPs | 整段历史读取 | 结束时状态 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Qwen3-8B | 37.1 | 0.0200 | 1.125 GiB | 5.11 | **291.3 GiB** | 1.160 GiB |
| V4-Flash | 60.3 | 0.0295 | **0.017 GiB** | 7.54 | **4.3 GiB** | 0.071 GiB |
| V4-Pro | 223.5 | 0.1093 | 0.039 GiB | 27.88 | 9.9 GiB | 0.102 GiB |
| Kimi K3 | 497.4 | 0.2494 | 1.020 GiB | 63.77 | 260.8 GiB | 0.641 GiB |

**哪一项需求更高，取决于问哪一项。** Qwen3-8B 的计算最省（prefill 37.1 TFLOPs，是 K3 的 1/13），但它的整段历史读取 291.3 GiB 是 V4-Flash 的 **68 倍**。生成 256 个 token 期间，Qwen3-8B 每一步都要重读整段 KV；V4-Flash 每步只读被选中的压缩块，整段只有 4.3 GiB。

这条对比直接决定部署形态：**计算受限的场景选 Qwen3-8B，访存受限或长输出的场景选 V4-Flash**。K3 在两头都不占优（计算最重、历史读取接近 Qwen），它的优势要在更长的上下文和 KDA 层占比更高的场景才出现——本请求只有 8K 级历史，没到 KDA 的收益区。

V4/K3 的 prefill 权重载荷按“逐层批内专家并集”累计，与 Dense 的“每算子读一次”不是同一口径，因此 MoE 的这一列远大于其驻留权重，**不能直接跨模型比较**。逐项名称保存在 `results/model-choice.json` 的 `weight_keys`／`read_keys`／`write_keys` 中。

## 使模型选择成立的质量条件

资源表**不足以选模型**。要让上面的选择成立，还必须满足：

1. **同一批消息上的检索都答对**。[paired-retrieval](paired-retrieval/README.md) 已实跑：Qwen3-8B 与 V4-Flash 各 8/8 通过。两者都满分，**不能据此排出质量赢家**——这组题太容易，没有区分度。
2. **长距离多键检索保持**。[multikey](multikey/README.md) 已固定四道题、每题 4,148 token，超过原 4,096 上下文设置，需要扩大上下文后重跑。这是真正能区分压缩／稀疏路径的题。
3. **压缩／稀疏在目标任务分布上的质量损失可接受**。V4 省下 68 倍历史读取的前提是被丢弃的历史确实不重要，这只能按任务测。
4. **输出长度与推理预算相同**。不同 reasoning 长度会改变整段成本，比模型差异更大（第 3 章）。

设备供给与链路代价在第 4、6、7 章加入；本实验**不据模型需求表给出硬件性能排名**。V4-Pro 与 Kimi K3 作为迁移练习保留在同一张表中。

完整数值见 [results/model-choice.md](results/model-choice.md)。

## 限制

- 各模型的接口项名称不同，本实验按模型分别取用，不合成统一分母。
- 统一 BF16 口径不等于 V4 的 FP8/FP4 或 K3 的 MXFP4 实际存储。
- 均匀路由是声明输入；集中路由会大幅降低 MoE 的权重载荷（见实验 2-6）。
- K3 取 compact 路径；expanded 路径的历史读取会大 10 倍以上（见实验 2-3）。
