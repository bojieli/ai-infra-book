# 12-6 有界传输事前协议

2026-09-09，在首次运行前固定。仅本机 127.0.0.1 TCP，应用自定义 JSONL/base64 帧，无 HTTP 基准、网络 sleep、WAN 仿真或数学扫描。

主进程为客户端，单独启动一个单线程服务器进程，服务器动态分配两个监听端口，共享会话状态。两条连接是两条逻辑传输路径，非独立物理链路。每次尝试两条连接均预先建立；复制每次向全部活跃连接发送相同请求，切换只发主连接，观察 EOF 后在已建立备连接重试。两者都按两帧一批拉取同一固定 16kHz、单声道、16-bit LE PCM（24 × 640 bytes）。每批服务端先发奇数帧再发偶数帧，确定性地检验应用重排，不称为 TCP 包乱序。客户端逐帧去重、缓存、按序解码并计算样本平方和，消费满 8 帧后发同一 cancel ID；收到取消 ACK 后再次请求音频，必须收到 cancelled ACK 且无更多音频，然后获取固定工具 JSON 结果，最后完成。取消及工具请求也按策略复制或切换；取消幂等。

故障：none；primary（请求音频 4/5 时在主连接响应前 shutdown+close）；endpoint（同一触发点关闭两条连接和监听器并退出服务器）。故障由收到真实请求触发，无定时模拟。共端点条件预期不完成、不收到取消 ACK；保留失败为负例，不补造结果。单路径失败时复制备份已在传输，切换待 EOF 后重发。每批必须排空所请求活跃路径的响应，所以此实现不测 first-wins 复制尾延迟。

先做每条件 1 次 smoke（6 次），独立验收后做每条件 5 次（30 次），每轮固定 seed 随机排列条件。每次 5 秒读超时、子进程退出 3 秒超时；异常保留完整目录，不覆盖原始记录。日志记录每一应用帧的方向、路径、时间、实际 payload/base64、SHA、wire JSONL 长度、双方 PID，以及关闭、EOF、消费、去重、取消和完成。payload 字节与应用 framing 分开计，均非 TCP/IP 链路或蜂窝字节。逐次保存环境、源码 SHA、fixture SHA、退出与端口拒绝连接检查、RSS 与 CPU 时间。只记录本机实现时间，不做隔离性能因果结论。

独立 analyze.py 不导入 run.py：重建 PCM 夹具，验证双方收发帧一致、payload SHA、消费有序唯一、真实平方和、取消 ACK/取消后无消费、工具结果、断连、重试、预期完成/失败、全部 6 条件及重复数、源码 hash 和资源界限。另对日志副本实施去重消费、ACK 缺失、payload 损坏三种内存变异，必须拒绝。失败原件全部保留，验收结果单列。

资源：标准库 socket/select，不启动线程、GPU/MPS/SSH 或子 agent；同时最多客户端和服务器两单线程进程；设置每进程地址空间上限 768 MiB，文件大小 16 MiB；总目录 <500MB，退出后验证监听端口关闭。绘图阶段单进程，BLAS 线程设为1。不操作其他服务。

未覆盖：RAW 分流、汇合瓶颈扫描、真实无线/WAN 抖动丢包/相关概率、MPTCP/QUIC、蜂窝字节与电量、TTS 模型、物理播放和设备取消。只证明该实现的可靠交付、去重、排序、软件取消与故障边界。
