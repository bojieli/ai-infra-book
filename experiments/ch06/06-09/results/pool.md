## 容量：总量够，仍然放不下

| 节点 | 容量 | 任务需求 | 本地缺口 |

| 0 | 64 GiB | 80 GiB | 16 GiB |

| 3 | 64 GiB | 32 GiB | 0 GiB |

- 总容量 256 GiB，总需求 192 GiB，**总量够**。
- 整任务迁移：80GiB job exceeds every64GiB node
- 增加本地容量：需要 16 GiB。
- 向池借用：唯一借用 16 GiB；池外仍有 80 GiB 本地余量无法被这个任务使用。
