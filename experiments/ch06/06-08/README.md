# 实验 6-8：超节点的历史设计选择（进阶推演）

对应正文 6.6。回到某一代 DGX 或 TPU，你会采用同样的组织吗？用当年公开输入复算一组 TP／PP 方案，再把本章固定模型放到 NVIDIA、TPU 与 UB 三种资源条件下，比较选择为何改变，并保留实际采用与本推演预测的差异。

## 独立运行

```bash
python3 run.py    # 现场调用 calculations/calc.py ub-scope，产物写入 results/
```

只需 Python 3.8+ 标准库。互联速率是**声明输入**，用于比较选择而不是复原历史设备性能。

## 当年公开输入

| 代际 | scale-up 范围 | 逐卡容量 | 组织 |
| --- | ---: | ---: | --- |
| DGX-1（2016，P100） | 8 设备 | 16 GB | NVLink 1.0 混合立方网格 |
| DGX-2（2018，V100） | 16 设备 | 32 GB | NVSwitch 全互连 |
| TPU v3 Pod（2018） | 1,024 设备 | 32 GB | 2D 环面直连 |

## 同一模型在三种资源条件下的选择

| 模型 | 资源条件 | 通信更优 | 单机 TP8 | 双机 TP4×PP2 | 远端带宽阈值 | 远端启动阈值 |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| Qwen3-8B | NVIDIA 风格 | 双机 | 2.096 ms | **0.924 ms** | 28.0 MB/s | 590.6 μs |
| Qwen3-8B | TPU 风格 | 双机 | 2.127 ms | **0.948 ms** | 27.7 MB/s | 592.7 μs |
| Qwen3-8B | UB 风格 | 双机 | 2.096 ms | **0.919 ms** | 27.8 MB/s | 590.9 μs |
| Qwen3-32B | NVIDIA 风格 | 双机 | 3.689 ms | **1.618 ms** | 19.8 MB/s | 1,040.2 μs |
| Qwen3-32B | UB 风格 | 双机 | 3.689 ms | **1.613 ms** | 19.7 MB/s | 1,040.6 μs |

两个结果值得注意：

1. **三种资源条件下的选择完全一样**，而且数值差别只有百分之几（0.924／0.948／0.919 ms）。原因在阈值列：**远端带宽只要超过 28 MB/s，双机就更好**——这个门槛低到任何一种互联都远远越过。真正决定选择的是**启动时间**（阈值 590 μs 以下双机更好），而三种条件的启动时间都在微秒级。
2. 换句话说，**在 decode 这种小消息负载上，互联的带宽几乎不影响并行方式的选择，启动时间才影响**。这与实验 6-4 的结论一致：小消息由轮次和启动决定。带宽的价值出现在 prefill 与训练那种大消息场合。

## 推演

**当年的选择**：2016–2018 年公开可见的模型远小于单机容量——DGX-1 的 8×16 GB＝128 GB 已经能装下当时任何公开模型的权重与状态。按当年输入复算，TP 只需覆盖单机，跨机以数据并行为主。

**当年能给出的预测**：把 scale-up 范围从 8 扩到 16（DGX-2）在当年很难用容量论证，只能用“更大 batch 的同步开销”论证。TPU 选择 pod 级环面则是另一条路线：把协作范围做大，但接受每跳带宽较低与拓扑固定。

**实际采用**：NVIDIA 走 NVSwitch 扩大机内全互连范围，TPU 走 pod 级直连环面——**两者都在 GPT-3 之前就已确定**。

**差异**：按当年容量输入，本推演给不出扩大 scale-up 的充分理由；实际选择是**按未来负载下注**的。差异不在算术，而在“为哪一类负载设计”。这与实验 1-8 案例 C 的结论互为印证：2019 年的容量数据支持不了统一互联的投入，2020 年的支持得了。

**放到今天**：把本章固定模型放到三种资源条件下重算，远端带宽越接近本地，跨服务器切分越早成为更好的选择。这正是 UB 风格路线要改变的那一项——**不是提高峰值，而是把机内速率延伸到更大范围**。

完整数值见 [results/historical.md](results/historical.md)。

## 限制

- 比较只针对**声明的串行通信预算**，不含计算、重叠与实际调度；任何逐卡容量不通过的候选都不参与比较。
- 互联速率是声明输入，不是 P100／V100／TPU v3 的实测值；本实验不复原历史性能。
- 历史组织的描述限于公开规格，不推断内部设计过程。
- 只比较 TP8 与 TP4×PP2 两个候选；完整的并行组合扫描见实验 6-2 与 6-3。
