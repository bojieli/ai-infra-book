# 异构流水线的容量与请求路径

2026-09-09。围绕第 6.2.3 节和实验 6-2 选读 [Helix 正文及工件附录](../../../proceedings/ASPLOS/2025/helix-reading.json)物理页 1–15，实际查看五页图像。本文只取能帮助读者判断放置与网络瓶颈的部分；第 7 章继续加上超节点边界，第 9 章继续检查请求和 KV 调度。没有执行作者模拟器或下载的代码，也没有运行模型。

## 先把资源换成相同单位

Helix 把给定层段在节点上的服务能力、节点网口和连接带宽换成 token/s，联合选择放置与请求路径。只按 GPU 算力平衡层数，可能把中间激活送到一条慢链路上。允许多条流水线共享节点，可以利用被固定配对闲置的计算能力；是否有效还要看新增路径的通信代价。

这个最大流对应固定的服务率、放置和网络抽象。论文另用 MILP 搜索放置，并设置求解预算；它不保证任意模型与负载下的实际部署全局最优。GPU 的处理能力依赖层数、prefill／decode、batch 和上下文，网络还存在启动、排队与竞争；平均吞吐不能代替单请求延迟。

## 从论文原型到公开框架

论文原型基于 **vLLM 0.4.0.post1**，采用 Llama-1-30B／Llama-2-70B FP16。实际单集群评估是 24 个单 GPU 节点与 10 Gb/s 网络；跨地域和 42 节点的高异构配置由模拟器评估。轨迹去掉输入大于 2048、输出大于 1024 token 的请求，不能直接代表长推理和 Agent 多轮负载。论文的 decode 输出吞吐与建模中的全部处理 token 也有不同分母。

工件的 [README](helix-readme.md)明确使用 dummy weights；它检验性能，不足以证明真实生成的正确性。[所读 Llama 阶段适配](helix-llama.py)也保留未实现的权重加载入口。这里记录的是 **2025-10-15** 的固定 master 提交 `8639497a4aaf1eb3b7594614cb0bbd376c1342b3`，不是论文发布时的代码快照。工件总目录只作定位，未将其全部文件或依赖计为已读。

对照 **vLLM v0.10.1** 的[并行指南](vllm-2025-parallel.md)，再看固定于 **2026-09-07** 提交 `537af2c3a4ba7462ddc9bc94ec7a4ea496da6d2e` 的[指南](vllm-current-parallel.md)和[层划分代码](vllm-current-pp.py)：框架支持不等长的连续层段，并可用 `VLLM_PP_LAYER_PARTITION` 指定每段层数。这能表达静态 PP 划分，不能仅由该选项推断已具备 Helix 的逐请求路径规划。所读文件没有证明整套框架是否集成某篇论文，也不据此声明整个框架缺少相应能力。

当前 [Qwen3](vllm-current-qwen3.py)继承 [Qwen2Model 的 PP 接口](vllm-current-qwen2.py)，非末段交接 `hidden_states` 与 `residual`；启用相应推测功能时还可能带辅助状态。对 TP=1、BF16、无辅助状态的教学配置，这两个同宽张量合计为 `2×4096×2=16384 bytes/token`。这是接口张量载荷，真实链路还要核对序列化、分片、控制信息和额外传输，不能当成抓包结果。

## 吞吐之外还要保留状态

Helix 给每个请求选定路径，后续自回归 token 沿同一路径执行；不同请求可以走相交的流水线。这没有消除路径上的 KV 状态，更不表示每个 decode step 都能无代价换卡。

[KV 估计代码](helix-kv.py)用实际输入长度加平均输出长度的倍数预留容量，再以高水位筛掉节点。README 也明确，低估可能造成模拟中的 KV 溢出。平均长度与安全系数不能代替最大容量证明；长尾输出要考虑限额、接纳控制或状态搬移的实际代价。

[独立算例](arithmetic.json)用真实 Qwen3-8B 的 36 层、18＋18 划分，配上明确假设的节点服务率和链路预算。31.25 MiB/s 链路按上述两个张量只能承载 2000 个处理 token/s，按一个隐藏向量则会误算成 4000；四节点容量网络的上界随之从误算的 14000 改为 12000。同一阶段保留的 4 GiB KV，在 8192／16384 历史长度下分别最多容纳 7／3 个序列，且这只是容量上限。计算脚本只枚举十六个割集并检查显式可行流，不运行完整模拟器。

这些数接入[已有模型并行案例](../../../../case-studies/model-parallelism.md)和实验 6-2 的选做变体。图 6-2 计划自绘同一组节点与路径的 SVG，并标明单位、最小割和 KV 驻留；不直接复刻论文的吞吐对比图。图与真实系统实验留待扩写时制作。

原始响应、失败分支定位及精确阅读范围分别见 [sources.json](sources.json) 与 [reading.json](reading.json)。本轮补足静态 PP、异构请求路径与实际接口载荷之间的差距，没有把所有框架或本届论文标成阅读完成。
