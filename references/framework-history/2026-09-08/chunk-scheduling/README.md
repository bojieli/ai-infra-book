两个 tag 对应提交的时间分别为 2024-05-05 和 2025-03-18，记录见 [v0.4.2 元数据](vllm-v042-commit.json)与 [v0.8.0 元数据](vllm-v080-commit.json)；这是提交时间，不冒充 GitHub Release 发布时间或特性首次合入时间。2024 的样本早于原笔记的两年窗口，用来避免把已有机制误记为 V1 首创。

历史文档的 512 token 预算来自当时 A100 的调优条件；当前文档对较低 ITL 与吞吐举出 2,048、8,192 以上的设置。它们不是跨版本通用默认，也不能推出最佳预算随时间单调增加。实际实验保存配置解析结果、模型、后端和请求分布。

文档用 decode 优先解释总体策略，源码则按运行／等待状态和多种资源约束实施；输出批次中的列表顺序也不能代替准入顺序。上述源码范围不包含所有分支，不能据此概括所有模式下的严格请求优先级。

教学落点为 9.1.3–9.1.5、实验 9-2，继续接第 10 章的 PD 与迁移；[具体推算](../../../../case-studies/chunking-and-state-transfer.md)解释相同 token 数、不同历史长度下的工作差异。三代来源只证明这些快照中的机制，不表示完整 vLLM 版本史已经读完，也不替代 SGLang／Ollama 的独立演进证据。
