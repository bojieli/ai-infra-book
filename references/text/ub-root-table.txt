2 Introduction
This document describes the UnifiedBus Root Table (UBRT), which serves as the root
structure of the UnifiedBus (UB) system for use with the Advanced Configuration and
Power Interface (ACPI). The UBRT provides the OS with the fundamental configuration
and architectural information necessary to initialize and manage the UB device.
During system boot, the OS searches for the UBRT in the ACPI tables. Once located, the
OS reads the UBRT header to determine the number of sub-tables, then uses the Pointer
values to access each sub-table. The OS then initializes the UB device based on the
information provided in these sub-tables.
If the UBRT checksum is invalid or the header fields contain invalid values, the OS should
treat the UB device as unavailable and log an appropriate error. The system should
continue booting, but the UB functionality will not be available until the issue is resolved.

4.3 UB Reserved Memory Information Table
In virtualization scenarios, the host OS SHALL describe the available memory range for
the UBC to the guest OS through the UB reserved memory information table. This
information table is reported by the VM BIOS. The physical machine BIOS does not need
to report this information table.
