四个官网指向的 ACM 论文集入口（ASPLOS 2024 三卷与 MICRO 2025）在普通下载和网页读取中均返回 HTTP 403，响应原样保存。公开 Crossref 元数据成功取得 [ASPLOS 2024 第一卷](crossref-3617232.json)，另外三个请求返回 HTTP 429，不能称为元数据成功归档。后续遵守服务限流继续核查出版方元数据，并匹配作者主页、机构仓库或作者预印本；保持正式发表版本与公开稿的版本区别。

联合日程导出含 `http://localhost/...` 的事件 URL，这只是导出配置中的值，不作为可访问论文链接。与研究无关的注册资料和参会者名单未纳入归档。

逐卷筛选与大纲取舍统一记录在[长期调研](../../../../research/2026-infra-survey/README.md)。后续[目录复核](../../catalog-review/2026-09-08/README.md)补上提取修正、跨年份出版映射及明确的读取范围，不据日程标题向书中增加技术结论。
