## 恢复调研后的独立推算

[标准库计算脚本](../../../../../research/2026-infra-survey/calculate_history_speculation.py)与[完整结果](../../../../../research/2026-infra-survey/history-speculation-arithmetic.json)已保存。用独立同分布的二元目标，穷举 40 组目标概率、确定性草稿和块长组合，检查截取前六个输出的联合分布，并以事件枚举核对每轮平均产出。这里只检查教学模型，不是 RhymeRL 或 vLLM 的复现。

固定目标 P(A)=1/4、P(B)=3/4，草稿长为 4。连续提出 A 或 B 的平均产出分别为 341/256 与 781/256 token，包含拒绝后的补偿或全部接受后的额外 token。假设普通 decode 为 1 ms/token，一轮验证 1.4 ms、历史查询 0.1 ms，则两者分别需要约 1.126 与 0.492 ms/token。第一种即使免费查询也无法在这个计时模型下获益；第二种仍需计算索引建立、传输与并发变化。额外暴露在关键路径上的 2 秒准备时间，按稳态节省估计约需 3,935 个输出 token 抵消，不把这个估计写成有限请求的精确时限保证。

容量变体假定 1,024 个 prompt、每个 8 条各 4,096 token 的历史：uint32 token ID 本身为 128 MiB；若完整索引表示假定每 token 32 字节，则为 1 GiB，新旧两份为 2 GiB，还需另计构建暂存等空间。32 字节是教学输入，不能作为论文实测常数；已包含的 token ID 不重复相加。
