4.3 Dynamic Shape–Aware Memory Planning
Memory is an essential resource in modern ML applications.
Most ML compilers can plan memory reuse by comparing
sizes of static-shape tensors and allocating a fixed set of
memory blocks ahead of time to reduce the runtime memory allocation. Normally, compilers cannot take the same
approach for compile-time unknown shapes and must rely
on runtime memory allocators. With symbolic shape abstractions, however, we can analyze and compare dynamic
tensor shapes and plan for their reuse accordingly. Figure 10
and Algorithm 3 show how we apply memory planning
with dynamic shapes. We first lower the foreign function
calls call_tir and call_dps_library to explicit memory
allocation and DPS calls (as in Figure 5), so we can expose
