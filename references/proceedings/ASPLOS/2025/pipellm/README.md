# PipeLLM 的作者正式格式副本

[原始 PDF](author-final.pdf)来自作者机构网站，[来源记录](sources.json)保留重定向、时间与哈希；`author-final.txt` 为 `pdftotext -layout` 派生文本。副本含正式 DOI、卷号及印刷页 843–857，共十五个物理页；没有逐字比对出版方 PDF，不宣称两者字节一致。

本轮读取物理页 1–13；六张 `views/` 页面实际查看，14–15 页参考文献未读。范围、图像哈希、观察及限制见[页级记录](../pipellm-reading.json)，框架与公开工件另见[专题说明](../../../../framework-history/2026-09-09/pipellm-swap/README.md)。

较早的 [arXiv v1](../public/paper-049.pdf)仍是本届逐篇 manifest 的代表副本，其十四页、原件哈希和摘要记录均保留。新增副本由 `selected_reading_pdf` 指明，只增加一个版本，摘要及独立论文数量不增加。
