## 论证证据

三条主要架构线为 Apple、NVIDIA、昇腾。作者当前没有昇腾实机；910 到 950 的结构与软件机制继续按公开材料展开，引用测量保留原条件。本书的跨平台实测以 Apple／NVIDIA 为主，不以相同分析假设的模拟代替昇腾实测。

- **昇腾 910A 的设计背景。** 作者提供了以 ResNet 为重要目标负载的历史背景。2019 年公告可核对训练基准；2022 年早期 DaVinci 论文同时分析 BERT、MobileNet、ResNet。最初设计过程与后来的适用性分别取证，具体取舍应注明作者经历、时间或设计资料。
- **昇腾 910C 的微架构变化。** 新增 CloudMatrix384 论文 v2（2025-06-18），§3.3.1 已披露双 die、每 die 24 AIC／48 AIV；§4.2.2 给出 MLA 融合、NZ 格式 KV 和 MTP 动态 tiling。v3（2025-06-19）改用“Ascend 910”并删减部分参数，两版分别归档。尚缺 910A → 910B → 910C 的逐项指令、通路、stride 变化及其设计因果；通用 CANN 指南不能独立证明某项能力由哪一代首次引入。详见[架构与执行比较](../case-studies/accelerator-architecture.md)。
- **动态 shape 与编程成本。** 已有 Ascend C 动态 tiling、Triton 和 NVIDIA TMA 的机制依据，不能预设昇腾不支持动态 shape，或 NVIDIA 无须显式搬运。跨平台开发工时、调优次数、形状覆盖、冷启动与稳态性能仍需在相同任务及相近抽象层次实测。
- **图执行。** 已归档 CUDA Graph 与 vLLM 设计，明确提交、设备启动、融合和图重放的不同成本；跨平台图执行仍需固定运行时版本，测量捕获范围、缓冲占用、动态批次与回退。
- **昇腾 950 的测量与交付。** 已取得芯片白皮书、路线图和 MWC 2026 公告，核内通路、产品配置与互联能力已有直接依据。尚须分别核实实际产品、交付状态及工作负载下的有效性能；8192 卡超节点上限与更大集群规模不能写成同一项实测结果。
- **近期模型训练总量。** DeepSeek-V4 的专家矩阵乘和 Qwen3.5 的注意力长度敏感性已在[训练计算量案例](../case-studies/training-compute.md)复算。各阶段 token 分配、辅助分支、重计算等信息尚不能闭合整次训练。Kimi K3 已核对版本也不足以给出完整训练 token 明细，不能从 GPU 时长或激活参数制造一个精确总量。
- **专用芯片的比较。** Groq、Cerebras、SambaNova、Taalas 与 Etched 的材料类型不同，包括论文、白皮书、产品规格和产品网页。特别是 Taalas HC1、Etched 的公开介绍，不代表已经取得完整 ISA 或微架构说明。厂商性能声明须保留模型、精度、输入输出长度、系统规模与测量条件。
- **同条件的性能与成本。** 尚需书中实际采用的跨厂商基准提交、配置、原始测量与功率记录。产品峰值和厂商推演不能代替相同质量目标、精度、序列长度及批量下的结果；端侧还要记录后端、温度与持续性能。
- **MacBook／RTX 配对实验。** 已核实当前 Mac 为 M2 Max（38 核 GPU、96 GB），作者确认 RTX PRO 6000 Blackwell Workstation Edition 600 W。Apple 与 RTX 规格、Ollama 0.20.7 固定提交的设备发现／Metal 缓冲和内核已归档；M2 Pro 仅作同代参照。尚需 RTX 主机配置、实际 runner 日志、同模型和量化的阶段测量、前缀缓存控制及整机能耗。见[配对案例](../case-studies/macbook-rtx-pro6000.md)，其中带宽算例不是实测。
- **异构 PD／AF。** A100 prefill＋H20 decode 已有算例与验证设计；H20 SXM5 96 GB 的官方型号可核实，完整资源规格及本书集群测量待补。AF 主案例已确定采用公开文档中的 RTX 4090＋双路 Xeon Gold 6454S，尚需本书实验机的内存容量、通道与 DIMM 配置、NUMA 设置、软件版本和完整运行记录。SOSP 论文的双 Xeon 8452Y＋A100／4080 结果按原配置引用。详见[异构案例](../case-studies/pd-af-heterogeneous.md)。
- **官方文档间的差异。** 已存 Trainium3 架构页与 NKI 指南分别列出 4.9／4.7 TB/s 内存带宽、16／20 个 CC-Core，尚无足够依据解释差异。两份原件分别保留，暂不以这些冲突参数作精确比较。
- **系统部件的具体规格。** 已有加速器系统与互联协议资料；选定网络和存储算例后，还需对应型号的 NIC、交换机、光模块、SSD、主机 CPU／内存及供电冷却参数，避免用芯片峰值代替整机能力。
- **平台调度和账单。** 已取得调度论文、Kueue、Kubernetes、OpenCost、OpenTelemetry 和 Firecracker 资料。书中的端到端案例仍需作者环境的作业到达、资源分配、用量事件、重试与对账记录；这些运行数据不能由通用文档代填。
