# First-paper evidence gate: insufficient

The predeclared 33 original non-repetition points and `N >= 2e9` holdout are preserved. No fitting ran and no synthetic observations were substituted. Replay with `PYTHONPATH=calculations/src python calculations/research/scaling-real-points/adapt.py` and `python -m unittest discover -s calculations/research/scaling-real-points -p test_adapt.py -v`.

Matching the author's published loss to actual validation logs revealed three validation-index populations: 6,400, 25,600 and 51,200 sequences of 2,048 tokens. The first two contain only below-threshold training models; the last contains only held-out models. These observed files do not substantiate the supplement's common 210M-token evaluation description. Neither pooled evaluation nor changed holdout is permitted by this protocol. Author model-label token budgets also differ from some launch scripts (e.g. 146m14b14b), and intended launch budgets do not prove achieved training steps. Author parameter estimates are not exact checkpoint counts; the independent review also records mismatches with Appendix S.

`adapted.json` retains all 33 rows, explicit exclusions, evaluation populations and the unexecuted fit result. `adapter-inputs.lock.json` verifies only the source/derived files needed to replay this decision. Independent N/loss evidence is in the sibling `scaling-real-points-independent` directory. This is a completed finite review of this paper, not completion of the overall real-data scaling-fit task. A separate Pythia investigation uses a separate paper/control group and does not combine these rows.
