# 实验6-9：内存池容量与快照访问

原文四台64GiB、需求80/48/32/32GiB。完整80GiB任务不能搬到任一64GiB节点；若允许拆分16GiB任务/数据，容量才有可行方案，执行成本未知。借用方案保留计算在节点0，远端16GiB放在节点1；本地空闲之和80GiB与全局净余量64GiB分别列出。

一、二、三个副本总物理占用192/208/224GiB，唯一数据始终192GiB。副本不自动提高单读带宽；穷举45组失败节点组合，按本地计算节点与实际完整数据副本判断任务不可用。未推断故障概率、检测/恢复时间或可靠性排名。

每次完整读取不变16GiB快照，频率1/60、1、20次/秒，带宽10/40GB/s，延迟2/20us，在途128/4096个256B事务，启动5us均为新增教学假设。有效速率上界min(B,Nq/L)，并明确假定乐观服务时长就是严格周期串行模型的固定服务时长；通过该条件不保证真实队列稳定。每个副本场景的24组访问有10组不增长积压，没有20Hz组通过。

[独立检查](independent-review.md)用GiB数据身份、显式存活节点和前8次到达核对3放置、45失败集合、72访问条件及576到达。公共实现、统一CLI及结果图已接入，见[公共检查](../memory-pool-integration/cli-check.json)。原研究候选保留为独立等值参照。
