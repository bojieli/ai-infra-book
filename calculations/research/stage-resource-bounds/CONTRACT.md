# C22 staged resource-bound contract (candidate under construction)

Consume existing real Qwen3-8B and V4-Flash inference accounts, never nominal 2NB. Stages are embedding/table setup, each complete decoder layer, then head. Layers are true serial barriers; independent operations within each layer may overlap ideally. Therefore sum(layer max_r work/rate) is a valid conditional lower bound for that serial-stage abstraction, not an asserted literal operator schedule. Global max_r(sum_layer work/rate) is separately weaker. No complete measured token latency follows.

Resources distinguish BF16/FP32-acc dense matrix, FP8/FP32-acc dense matrix, FP32/FP32 vector work, each named special/conversion primitive, and conditional memory-interface bytes. FP32 matrix and ordinary scalar work share one vector denominator and are summed before max. Device admission calls existing exact precision/accumulator/unit/sparsity selector; Huawei Cube is distinct from Vector, Apple GPU is distinct from Neural Engine, TF32 is never full FP32 and structured sparse peaks never replace dense work. V4 routed weight storage is FP4 but the pinned kernel casts to FP8 for FP8xFP8 GEMM.

Qwen uses explicitly selected BF16 weights/activation/KV and BF16 score/probability interfaces (score_bytes=2); reductions are the existing FP32 scalar algorithm. This declared materialization format supports BF16 QK/PV admission; it does not silently divide FP32 probability operands by a BF16 tensor peak. Cast/internal workspace work remains outside the existing reference account and is not claimed complete.

V4 mapping follows fixed runtime source: ordinary quantized projections/shared/routed experts are FP8 GEMMs; grouped wo_a and index_weights_proj plus attention/index scores are BF16; compressor projections/router/mHC/logits are full FP32. Fixed scalar/special subtotals remain exactly conserved by layer, with partial coverage retained. Logical effective matrix FLOPs are used; sparse/expert tile alternatives are not silently added a second time.

Official memory bandwidth supplies a denominator only after an explicit materialized-interface scenario: listed operands must traverse that interface per counted operation. Qwen supplies existing standalone-operator read/write operands. These are not observed HBM or an unconditional traffic bound. V4 does not currently supply a complete corresponding stage byte account; required interface work stays unknown unless caller supplies explicit per-stage byte demands. Do not convert checkpoint capacity or uniform BF16 comparison bytes into traffic. Known compute-only resource bounds remain useful while a combined unknown interface/rate result stays null. Caller-supplied rates or byte demands are marked assumptions; official unknown values are retained alongside them.

Capacity uses necessary weights+KV only for the declared Qwen BF16 storage contract. V4 checkpoint payload plus state is a comparison, not even an unconditional runtime necessary lower bound: hash tables change I64 to I32, and other runtime conversions differ. It cannot prove actual runtime capacity or trigger a runtime hard failure. Failure of the Qwen necessary capacity budget invalidates that device scenario; being below capacity is not full execution or peak-memory proof. Apple nominal unified capacity is shared with CPU/OS; no reserved memory is invented.

Official NVIDIA/Apple/Huawei profiles and hypothetical independent resource changes are separate scenarios. Missing required rates propagate to complete-accounted bounds while known-resource contributions remain visible. The original account's coverage gaps are not closed by providing denominators. Full runtime/traffic/peak remain unknown.

FP32 vector execution is an explicit logical provider choice, including ordinary scalar work; it is not proof that every source elementwise instruction actually runs FP32. Named special/index/format operations retain individual rate units (calls, comparisons, entries or elements per second), not FLOPs denominators. Global/serial bounds are conditional on the specified layer barriers and materialization/provider contracts; cross-layer pipelining is not silently assumed to obey them.
