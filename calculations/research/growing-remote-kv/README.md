# C36：增长KV的所有权与通信账

复用已锁定Qwen3-8B和Qwen3.6-35B-A3B官方配置/实现。分别读取完整attention层数与KV头维度，不把Qwen3.6的30层线性状态按序列长度展开。每请求每位置历史为147456/20480 bytes；Qwen3.6另有64880640 bytes固定本地递推和卷积状态。

两种声明放置：

- `remote_all`：初始化向每个副本复制prompt，之后每步从一个副本读所有旧位置，新位置发给全部副本；共享发送接口串行，并等全部副本提交后才能在下一步使用新epoch。
- `remote_prefix_local_tail`：远端prompt不变，新增位置留本地；每步远端读prefix、本地读已有tail，新tail不产生副本追加发送。必须付本地tail容量。

P=8192、G=128、B1、两副本时：

| 模型 | 初始复制bytes | 旧历史远端读bytes（全远端） | 追加副本bytes |
|---|---:|---:|---:|
| Qwen3-8B | 2415919104 | 155817345024 | 37748736 |
| Qwen3.6-35B-A3B | 335544320 | 21641297920 | 5242880 |

旧历史位置和为GP+G(G−1)/2，当前位置操作数另计。完整attention QK/PV包括当前位置，但不是全部模型工作。时间轴只包含声明的startup+bytes/B通信骨架，没有把KV生成计算时间设定为真实零耗时；实际decode和整任务可行性保持未知，预算只检查tail。

[独立检查](independent-review.md)显式维护每个副本的位置集合，核72场景、16预算边界、12非法/超上下文情况和零步边界。已接公共CLI、9场景及[18次CLI检查](../growing-kv-integration/cli-check.json)，研究候选留作完整数据等值参照。初始化发送已计；原始prompt源是否释放不推断。控制消息、故障检测/恢复、计算/通信重叠、完整驻留和实验6-10综合选择仍待。
