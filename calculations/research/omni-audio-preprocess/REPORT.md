# C77 PCM frontend candidate delivery

A one-second 16 kHz FP32 mono waveform produces 101 STFT frames, drops the last before magnitude/mel work, keeps 100 mel frames, and supplies 13 positions to the existing audio encoder geometry. Its mel projection is **5,145,600 FLOPs**; expanded known per-call scalar work is **87,306 FLOPs**, with FFT/complex-absolute internals separately unknown. The valid FP32 mel endpoint is **51,200 bytes**. Operand-interface read/write totals are **1,790,168 / 1,276,368 bytes**, not measured DRAM traffic or peak allocation. Four complete result ledgers are under `results/`.

The default source-path cap is **30 seconds**, despite serialized 300-second fields. This follows the fixed constructor and is confirmed numerically. It must be shown to readers rather than quietly preserving an erroneous 300-second execution assumption. Mixed-length mask counts likewise follow the full batch padding geometry; 479 samples alone produce 2 valid mel frames, while the same length padded alongside 800 samples produces 3.

The source graph has exact padding/STFT/FFT-input/output dimensions, window arithmetic, magnitude/power, mel projection, clamp/log/max/normalization, masks, and valid-frame gather. FFT work is not guessed from a generic logarithmic formula. A runnable full-complex mixed-radix reference separately performs 52,800 scalar operations per transform; it is not the optimized library backend and is not added to source totals. Cold filter setup and per-call window construction are visible rather than free. Fixed native Hann creates 401 values and narrows to400, preserving the discarded-endpoint work and 1604-byte underlying buffer.

Six unit tests pass. Four full numerical comparisons have exact masks and maximum mel absolute error 3.1858683e-5 against official FP32 code; the independent reference uses FP64 and explicitly permits1e-4. FFT comparison error is 1.4211e-13. Seven source-executed length/cap cases and three reflect-pad rejection cases pass. This is selected pinned-source execution with explicit container shims, not full model execution or measured hardware performance. See `numeric-verification.json`.
