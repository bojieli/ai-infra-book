# 原文到计算实现的复核入口

`sources.json` 捕获十三章正文、十三章扩写资料和所有案例笔记，初次收录 84 个文件、1243 个文本块，其中正文有 240 个小节和 117 项练习。文本按原文保存，不根据是否出现“实验”或“计算”来排除内容。标题、位置、SHA256、实现工作包和审查状态分别记录。

初次捕获不等于完成范围审查。后续逐块对照 [PLAN.md](../PLAN.md) 的 C01–C76，登记可计算项、所需输入及实现证据；非计算叙述也需经过明确审查才能移出待办。工作包完成后，仍应核对该块中更具体的变体、数字与旧算式是否全部覆盖。

`legacy-scripts.json` 是旧专题脚本的迁移候选；旧研究原件先保留，不批量删除或让它们成为第二套不一致公式。源文件变化后运行 `python3 calculations/calc.py inventory` 检查，再用 `--refresh` 更新；相同内容保留审查状态，变化内容重新待审。
