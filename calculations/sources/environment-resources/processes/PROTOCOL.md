# 运行前协议

补测独立 Linux 工具进程的资源，非模型、VM 或容器实验。九组随机顺序：等待/突发、CPU/突发、CPU/间隔150ms，各三轮，每组四个真实子进程。每进程分配并触碰64MiB；等待400ms或执行固定250000次SHA256更新。并发进程数不等于固定CPU核数，不绑核。每10ms目标间隔读各子进程VmRSS和CPU ticks，保留实际采样时间、启动和回收时间。进程自身报告CPU与结果，以独立hash检查工作没有被跳过。

RSS求和重复统计共享页，不当作物理内存或PSS；采样积分漏掉启动前与短瞬态，只作为观测到的RSS驻留。测试不修改GPU服务或calculations，原11-1封存件不变。对照有两个维度，等待与CPU不是等量工作，禁止把墙钟差归因于单一调度优化。
