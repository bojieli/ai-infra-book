# 3-3 更宽预算：运行前协议

首批44候选均在1024总输出token上限截断，24任务全部无合规最终答案。本补测把每候选总上限改为4096，仍包含thinking与最终答案。run.py对首批唯一源码变化为max_tokens；tasks.py逐字一致，baseline.json记录父manifest与源码哈希。

四题、两轮、三策略24组44候选；同序列与随机种子，serial两个独立候选，parallel同引擎同时两个，adaptive元素数<=8一个/其余串行两个。有效严格JSON答案多数投票，平票第一个；真值只评分，不挑答案、不决定预算。保持APCoff/eager、两序列、512块、6GiB KV、同Qwen3-8B。每组所有请求与失败均计入耗时/token。实际长度不同不当等量计算，串并行同seed不保证输出一致。

此批是看到截断后明确追加的诊断，非事先独立盲测；旧数据保留，不合并掩盖失败。更宽预算仍不足时保留失败，不能从思考文本中抽数字凑答案。没有实际付费/能耗与KV块峰值，不用配置值冒充测量。所有第一轮实验结束后才做最终跨session论文复核。
