## Mess 的采用范围

[物理页 3–6](../../references/proceedings/MICRO/2024/mess-reading.json)已读，表 I／图 3 已实际查看。重点是怎样测量并解释供数不足：探针与流量发生器分工、读写组成、实际计数器字节、加载后延迟及微基准与应用口径。模型端到端分析仍保留地址转换和 OS 工作，不能沿用微基准中排除开销的口径。

[访存并发算例](../../case-studies/memory-bandwidth-and-concurrency.md)沿用 Qwen3-8B 的 8K 历史 KV，共 1.125 GiB；用明确假设的事务大小、并发、延迟与接口上限，计算资源上界怎样变化。只加入现有 1.3.3、实验 1-4、图 1-3 和 4.3.3，没有增加实验或配图编号。教学计算经独立复算，真实框架／设备测量仍是后续实验计划。

原稿 H100 的板卡／存储频率组合尚未核清；正文与表 I 还互换了 Graviton3／A64FX 的两项延迟。图 3 的抽取文本含不可见的重复图标文字，核对图像后未采用这些数值。本文不把设备表移作当前规格，也不把当时的模拟器误差移作当前版本结论。完整模拟实现、CXL 曲线、应用 stress score 和 artifact 未计入本次选读。

首批其余候选优先比较 Duplex 的逐专家工作量、vTrain 的配置预测和 TACOS 的通信生成，只在它们增加既有章节未解释的设计判断时采用。SN40L 的已有引用不自动证明本阶段已读全文；14 份 PDF 的页数也不等于已读页数。

| 14 GPU-to-CPU compiler/runtime | 备查 | GPU 线程到 CPU 执行的迁移需要匹配编译和运行时，保留可移植性背景；通用 benchmark 的收益不能代替 KTransformers 专家路径或矩阵精度相同的比较。 |
| 15 Fine-Grained Program Versioning | 备查 | 运行时依赖检查与回退可放宽静态优化条件；作为第 5 章合法性背景，现有特化与反馈案例已覆盖主线，不另增 LLVM 优化专题。 |
| 22 SUV | 正文候选 | 编译器推断访问语义，选择固定驻留、边界预取和按需迁移；待读超额订阅、HBM 预留与错误判断代价，再与现有显式权重卸载比较。 |
| 23 STAR | 正文候选 | MIG 分区仍可能共享地址转换资源；待读实际芯片、TLB 干扰和新硬件条件，检验第 11 章隔离与资源预算，不宣称当前全部 MIG 均有同样边界。 |

| 27 NoCap | 排除 | 零知识证明的生成、传输与验证属于密码协议，虽然包含可验证 ML 用途，也不直接补充现有推理与训练性能案例。 |
| 31 LUCIE | 备查 | chiplet 与 interposer 的模块化、放置及制造成本可作第 4 章背景；仅机构摘要已读，不将特定拓扑成本或上市时间当作通用芯片结论。 |
| 42 BBS / BitVert | 备查 | 对 bit-level 稀疏还需核负载均衡、编码与专用执行；其二进制剪枝可能改变质量，不等同于透明低位宽或现成 Tensor Core 功能。 |
| 46 PIFS-Rec | 正文候选 | 在 CXL fabric switch 近数据处理 embedding，比较交换位置和缩减流量；待读行业 DLRM 访问、链路和硬件条件，不直接套作 KV 池或普通 CXL switch 能力。 |
| 55 Qoncord | 排除 | VQA 的噪声保真度、迭代和 restart 调度不同于 LLM RL；不因名称包含调度就扩展量子云案例。 |

| 66 Real GPU NoC | 正文候选 | 真实 GPU 内部的位置、分区与存储路径影响延迟和带宽；待读测量隔离、架构范围及重现条件，再校准第 4 章供数模型。 |
| 67 MINT | 排除 | DRAM 内 Rowhammer 跟踪与刷新约束超出本书主线，不展开安全阈值和攻击模式。 |

| 69 ImPress | 排除 | Row-Press 与 Rowhammer 的电荷损失和防护兼容性不是模型内存容量或服务缓存问题，不展开 DRAM 安全设计。 |
| 71 Self-Managing DRAM | 备查 | 维护操作与正常访问的重叠可作有效带宽背景，但需要 DRAM 接口及芯片修改；保留会后 v9 和作者字段差异，不用作当前 HBM 已有能力。 |
| 78 LIBRA | 排除 | tile rendering 的跨帧局部性和光栅化工作分配属于图形流水线；沿用已有 AI 访存与并发例子，不增加商业游戏专题。 |
| 81 LoAS | 排除 | 双稀疏 SNN 的时间步、脉冲编码与 inner-join 有特定模型语义；不把 temporal parallelism 当作 Transformer token 并行或 MoE。 |
| 92 SOFA | 正文候选 | 稀疏预测、排序与正式 attention 的跨阶段分块可以交换额外计算和 IO；待读近似精度、质量及专用加速器条件，与当前 V4 索引案例比较后再采用。 |
| 93 RAHP | 备查 | HyperGNN 的顶点／超边共享计算与不规则访存可作复用背景；FPGA 的模型、软件基线与现有 LLM 不同，暂不扩大网络类型。 |
| 101 Scalar Vector Runahead | 备查 | 顺序核预先展开独立访存可作第 4 章依赖与并发背景；图／数据库的推测执行不同于 LLM 推测解码，已有 Mess 案例先保留。 |
| 103 Mosaic | 备查 | serverless 函数的微架构状态驻留需要专用 CPU 与调度配合；不等同于 E2B 的 VM 快照、软件容器预热或现有 CPU 免费特性。 |
| 108 Cambricon-LLM | 正文候选 | B=1 的大权重工作集由 NPU 与带计算能力的 NAND 协作；待读真实字节、ECC、精度和硬件评估，不能把普通 SSD 卸载当作该专用芯片。 |
| 109 BABOL | 排除 | NAND 封装控制信号和软件定义 flash controller 超出本书 SSD 层状态搬运的范围，不扩展完整闪存控制器开发。 |
| 117 HgPCN | 备查 | 点云预处理和输入结构化可能主导端到端时间；已有 RAW／语音／Computer Use 足以承担这类判断，保留备查并维持当前第 12 章结构。 |
| 120 PyPIM | 备查 | Python tensor 到 ISA／PIM 微操作的完整抽象可作第 5 章背景；数字 memristive PIM 模拟不能证明普通 Python 或现有 GPU 获得相同收益。 |

比较落点按当前章节内容确定：第 4 章检查实际供数条件，第 5 章检查同步合法性与优化反馈，第 8、9 章检查卸载、池化和专用硬件的成本，第 11 章检查隔离与环境边界。先与既有案例比较，再决定是否补一句推导或替换案例，不为每篇候选增加小节。HgPCN 只作备查，维持第 12 章图像精修、语音和 Computer Use 的精简安排。

六张实际查看的页面用于处理分栏摘要、无 Abstract 标签、作者字段和机构封面；不将旁边的图或介绍段落计为正文选读。Self-Managing DRAM 的会后 v9、SOFA 的作者拼写版本、Fine-Grained Program Versioning 的路径年份分别记录。同名的 EuroSys Trinity 已与正确的 MICRO FHE 稿分开，前者不计入本届数量；AdapTiV 公告只完成题名核对，仍在未读摘要范围内。
